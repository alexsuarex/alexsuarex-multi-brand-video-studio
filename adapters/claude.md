# Claude adapter

## Claude Code

Instala la carpeta completa como:

```text
~/.claude/skills/multi-brand-video-studio/
```

Para compartirla con un repositorio concreto, usa `.claude/skills/multi-brand-video-studio/` dentro del proyecto.

## Claude.ai

Empaqueta la carpeta sin `.git`, renders ni secretos y carga el ZIP desde la configuración de Skills. Conserva `SKILL.md` en la raíz del paquete.

Referencia: [Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview).
