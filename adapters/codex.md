# Codex adapter

## Instalación local

Clona o copia el repositorio completo en:

```text
~/.codex/skills/multi-brand-video-studio/
```

El archivo que debe quedar en la raíz es `SKILL.md`. Inicia una tarea nueva o vuelve a cargar el entorno para que aparezca en el inventario de skills.

## Uso

Menciona la skill por nombre o pide crear/planificar una campaña de video multi-marca. Codex debe leer `SKILL.md`, cargar referencias según la fase y usar las herramientas locales disponibles.

Para repositorios de equipo, también puede copiarse bajo `.agents/skills/` dentro del proyecto cuando ese entorno la descubra.
