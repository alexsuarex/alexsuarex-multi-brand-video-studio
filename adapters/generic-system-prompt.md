# Adaptador para agentes sin soporte nativo de skills

Usa este texto como instrucción de sistema o de proyecto y adjunta el repositorio:

```text
When the user asks to plan, create, edit, scale or validate a short-form video campaign, read SKILL.md from the attached multi-brand-video-studio directory and follow it as the production method. Load only the referenced files needed for the current phase. Keep brand, avatar, voice and provider independent. Persist decisions in the supplied JSON schemas. Never claim to have used an unavailable module or produced a render that the current environment cannot create.
```

Si el cliente no ejecuta scripts, aplicar manualmente `references/quality-control.md` y entregar los JSON para continuidad.
