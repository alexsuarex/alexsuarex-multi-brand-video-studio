# Cursor adapter

El repositorio incluye `.cursor-plugin/plugin.json` y un `SKILL.md` raíz. Una vez publicado, añádelo como plugin desde GitHub cuando el cliente lo permita.

Si se usa como contexto de proyecto sin plugin:

1. Conserva el repositorio dentro del workspace o como submódulo.
2. Crea una regla de proyecto que indique leer `multi-brand-video-studio/SKILL.md` cuando se planifique o produzca video.
3. Mantén referencias, esquemas y plantillas junto al archivo raíz.

Referencias: [Cursor Plugins](https://prod.cursor.com/docs/reference/plugins) y [Cursor Rules](https://prod.cursor.com/docs/rules).
